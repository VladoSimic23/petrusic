# Sanity Studio

Ovaj direktorij sadrži Sanity Studio i sheme sadržaja. Za monorepo postavke, GitHub i deployment pogledaj [upute u korijenskom README-u](../../README.md).

Za lokalni razvoj:

```sh
npm ci
npm run dev
```

Za objavu na Sanity hostingu koristi `npm run deploy` nakon prijave u Sanity CLI.
